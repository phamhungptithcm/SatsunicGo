## Shared composition contract

Use a compact heading with task title and labeled refresh/action in one row. List items place meaningful title, status and decisive facts first; secondary IDs/timestamps/reasons remain readable with wrapping or native disclosure. Never invent a human order number, truncate distinct identity without full access, or hide financial consequences. Shared decorative SVG icons use aria-hidden; every actionable icon retains a visible label or verified accessible name. Primary action is reserved for the actual next task, not arbitrary buttons. List row differs from detail panel; no universal oversized panel padding. Desktop groups facts/actions horizontally; mobile stacks deliberately with minimum touch areas. Keyboard order follows reading order, visible focus, reduced-motion support.

Loading, empty, error, offline, partial/stale, disabled and recovery states need explicit semantics. Error includes actual available recovery; empty appears only after verified successful result. Never fabricate total counts from paged rows. State layouts remain compact rather than a blank full-height screen. Preserve all monetary totals/units, holds, explicit acceptance/confirmation, immutable history, operation identities, server CAS, role guards, private queries and print statements. No backend/schema/index/deployment changes in this delta.
